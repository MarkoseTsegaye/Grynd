Grynd — Active-workout logging rework

Four changes to the logging screen: a dismissible log pad, a readable set table that matches the new History rows, a slim rest timer, and RIR / notes moved inline — off the modal that currently discards whatever you already typed.

1 · Dismissible padGrab handle + chevron collapses the keypad to a 52px bar, handing the whole screen to the set list. Tap anywhere on the bar to bring it back.
2 · Set tableAligned columns instead of wrapping pills. Last week's sets sit inline as dim ghost rows you overwrite as you go — no separate cramped header line.
3 · Slim rest timer100px card → 38px bar with the countdown as a background fill. Dismissable with ✕, +15s inline.
4 · RIR / notes — BUGConfirmed: tapping “Plates · RPE · Note” calls resetLogForm() and wipes the weight and reps you just typed. Now inline panels that keep your entry and attach to the set being logged.
