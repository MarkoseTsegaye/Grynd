Grynd — Plate-loaded docked entry

Same skeleton as the regular QuickLogBar keypad — two fields, quick flags, a pad, and Log set — but the pad is context-sensitive: plate buttons when the weight field is active, the number keypad when reps is active. No bar weight, no doubling — it logs exactly the per-side sum you load. Multiples of a plate are allowed. Replaces the old bottom-sheet plate picker for exercises marked plateLoaded.

How it maps to the app

• Weight logged = sum of plates on one side. No 45 lb bar, no ×2 — this drops the barbell math for machines. Implementation: log weightKg = Σ(perSide) directly instead of computePlateWeightKg() (bar + 2×). Straight-barbell exercises, if ever needed, would be a separate mode.
• Plate set adds 2.5: LBS_PLATES = [2.5, 5, 10, 25, 35, 45]. (kg micro-plate — 1.25 or 2.5 — is a quick follow-up if you want it.)
• Multiples allowed: tapping a plate increments its per-side count (addPlate already does this) → 45×2, 45×3…; ⌫ / Clear use removePlate.
• Pad switches on field focus — plate pad for weight, number pad for reps.
• Reuses existing plates / addPlate / removePlate state in useWorkout; the bottom-sheet picker becomes a docked pad, auto-selected for plateLoaded exercises.
• Decimal for non-plate weights (out of scope, requested): the regular keypad's · key already feeds a decimal weight — verified in-app.
